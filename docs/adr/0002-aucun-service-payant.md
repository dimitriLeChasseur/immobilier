# ADR 0002 — Aucun service payant

- **Statut** : accepté (reconstitué le 04/11/2026 depuis `CLAUDE.md`)
- **Contexte** : projet autofinancé, marge faible sur un rapport à 2,99 €.
- **Décision** : uniquement des API, hébergements et outils gratuits ou ouverts (SonarQube local, Supabase auto-hébergé, sources publiques) ; OpenRouteService reste facultatif.
- **Conséquences** : chaque nouvelle source passe par `research` (licence, quotas) ; certaines données manquent (bruit de 5 départements, inventaires récents) et le README les liste en « Limites connues ».
